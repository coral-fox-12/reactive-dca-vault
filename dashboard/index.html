A self-running cross-chain DCA vault — set a schedule once, the vault buys for you. Built for the Reactive Omni Buildathon (“Set It and Forget It” track, $2,000 1st prize). No bot, no keeper: a reactive contract on Lasna fires on a CRON schedule and calls back to Base Sepolia, where the executor swaps on Uniswap V2.

⏸ Schedule currently PAUSED — unpaid SYSTEM debt

SYSTEM debt on the DcaReactive contract is 0.0167138 lREACT, larger than the contract's own balance of 0.0074661 lREACT. While debt > 0 the CRON subscription stays paused and the next tick never fires.

How debt works, in one line: every tick accrues a fee on Reactive's SYSTEM contract (0x8888…8888); topping the reactive contract up and calling coverDebt() pays it from the contract's own balance and resumes the schedule.

⚙️ How it works

  1. Fund once. The user deposits ETH into the DcaVault on Base Sepolia and creates a schedule (token, fixed amount, interval) — then never touches it again.
  2. CRON fires. Reactive's SYSTEM contract emits a Cron100 event on Lasna roughly every 2 minutes; the DcaReactive contract is subscribed and its react() runs — no bot, no keeper, no polling.
  3. Callback. For each due schedule, DcaReactive requests a cross-chain callback to the DcaExecutor on Base Sepolia (only the real reactive contract can trigger it — the executor checks the callback sender).
  4. Swap. The executor pulls the fixed amount from the vault, swaps it for DCAT on Uniswap V2 (5% max slippage, on-chain price check), and sends the tokens straight to the user.

Cost reality (measured live): ≈ 0.017 lREACT per buy, dominated by the callback — not the tick rate. The schedule pauses itself when SYSTEM debt exceeds the contract's balance; topping up + coverDebt() resumes it.
